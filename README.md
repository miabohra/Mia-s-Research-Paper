# Mia-s-Research-Paper
The Relationship Between Educational Attainment and Social, Economic, Political, and Environmental Indicators
Overview
This repository contains the Stata code used for the statistical analysis in the study, The Relationship Between Educational Attainment and Social, Economic, Political, and Environmental Indicators.
The study examines the relationship between educational attainment and a range of social, economic, political, and environmental indicators using cross-sectional data from 2022.
Data
The data used in this study were obtained from the World Development Indicators (WDI) database of the World Bank.
The analysis uses country-level observations from 2022. The dataset includes measures of educational attainment and outcomes related to health, literacy, labor force participation, economic performance, savings, research and development, political stability, government effectiveness, rule of law, voice and accountability, and carbon dioxide emissions.
Code
The Stata .do file in this repository contains the code used to:
Prepare and clean the data
Conduct the statistical analyses
Estimate regression models
Conduct robustness and outlier sensitivity analyses
Generate the results reported in the study
Data Availability
The underlying data are publicly available through the World Bank's World Development Indicators database.
World Bank. World Development Indicators. https://data.worldbank.org/
